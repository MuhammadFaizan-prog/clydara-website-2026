# Application Flow (Appflow)

## 1. Primary User Journey
1. **Landing & Hero**: User loads page, observes staggered entrance of hero headlines, avatars, and dashboard preview.
2. **Social Proof (Logo Ticker)**: Infinite scrolling logos demonstrate client credibility.
3. **Agency Mission (About)**: As user scrolls, the value statement illuminates word by word.
4. **Portfolio Discovery (Works)**: User explores high-impact client projects with interactive dots.
5. **Capabilities (Services)**: User toggles between Web Design, Brand Design, and Dashboards.
6. **Leadership (Founders)**: User reviews founder profile, timeline of credentials, and social links.
7. **Pillars & Values**: Clear rows define agency principles.
8. **Action Point (CTA)**: Prominent "Get Started" and "Contact Us" actions.
9. **Proof & Results (Testimonials)**: Metrics and interactive project case cards.
10. **Footer Navigation**: Direct links to all sections, social channels, and top-of-page return.

## 2. Responsive Breakpoints
- **Desktop (>= 1440px)**: Full scale layouts, maximum typography size.
- **Laptop (1024px - 1439px)**: Proportional scaling of display headers.
- **Tablet (810px - 1023px)**: 1-column portfolio grid, stacked layouts.
- **Mobile (<= 809px)**: Full-screen mobile drawer, optimized tap targets, adapted typography.
